# Starbie - Desktop Tamagotchi

A custom star-shaped desktop pet powered by a Seeed XIAO ESP32-C3 microcontroller.

## Overview
Starbie features an OLED display, an MPU6050 accelerometer for tilt/shake controls, a DHT11 sensor, and interactive buttons, all packed into a custom star-shaped PCB layout designed in KiCad.
